Recall Safety Canada

React Native, TypeScript, PostgreSQL, Python

Developed during StormHacks 2025, Recall Safety Canada is a mobile application that helps users stay informed about Canadian product recalls and safety alerts. Working as part of a team, I implemented React Native components that displayed dynamic recall information retrieved from a PostgreSQL database. The application provides users with a clean and accessible interface for browsing important safety information and demonstrates my experience building data-driven mobile applications.

Generous Rounds

JavaScript, MongoDB, OpenAI API, Flask, Python, HTML/CSS

Created during StormHacks 2024, Generous Rounds is a charitable giving platform that rounds purchases up to the nearest dollar and donates the difference to a charity selected by the user. I contributed to integrating the frontend with MongoDB for data storage and retrieval while also connecting OpenAI APIs to recommend charities based on user prompts. This project strengthened my experience working with databases, APIs, and full-stack web development.

Squid Games Database

JavaScript, SQL, HTML, CSS

Collaborated with a team to design and implement a database system inspired by Squid Game, modelling relationships between players, games, guards, and other entities. I developed dynamic SQL query generation based on user input, enabling filtering, aggregation, and data retrieval through a web interface. The project also incorporated asynchronous fetch requests to communicate with an Oracle database and support CRUD operations.

Heart Disease Classifier

R, Tidyverse, Tidymodels, Jupyter Notebook

Developed a machine learning classification model capable of predicting heart disease using patient cholesterol and blood pressure measurements. The project utilized data wrangling, cross-validation, variable selection, and standardization techniques to improve model performance. A k-nearest neighbours algorithm was trained and evaluated using the Tidymodels ecosystem, providing hands-on experience with practical data science workflows.
